An entry for the [make.fun bounty](https://make.fun/bounty/u-carbon-forge-snooze-button-roast-14cbafc6): one line roasting an alarm clock that goes off at 6 AM on a Saturday.

The script drafts thirteen one-liners by hand, grades each on five craft axes (on-brief, laugh, freshness, tightness, voice), picks the highest total, and writes it to `/output/entry.txt`, verifying the file against its SHA-256 digest afterwards. The winning line is "My alarm rang at 6 AM on a Saturday, and I realised the snooze button is the only relationship I've ever committed to."

## How to run

Run `python3 ./main.py` from this directory.

The program prints the winning line and leaves it in `/output/entry.txt`. Re-running produces byte-identical output.
